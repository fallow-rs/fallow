### Fixed

- **A config glob that parses but does not compile is now a config error.** A glob with brace groups that nest too deep for the matcher, such as `a{a{a{...}}}` with 130 levels, passed the config check and then stopped the run with a panic. Fallow now compiles the matcher of each config glob when it loads the config. Such a glob gives exit code 2 and an error that names the config field. A `workspaces.settings` key whose matcher does not compile selects no workspace. The same glob in an `import.meta.glob()` call, a negated workspace pattern or a `publicPackages` entry now matches no path instead of a panic.
- **A boundary preset matches a tsconfig `rootDir` with glob characters as a literal folder.** A `rootDir` such as `src[` stopped the run with a panic, and a `rootDir` such as `src[a]` matched no file. The preset zones now escape the source root.
- **The keyframes check of Sass and Less files no longer panics on a statement that starts with a multibyte character**, such as a byte order mark.
