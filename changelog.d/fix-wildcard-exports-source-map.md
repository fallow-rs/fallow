### Fixed

- **A wildcard `exports` target in build output now maps to its source files.** A package with `"./*": "./esm/*.mjs"` or `"./*": "./dist/*.js"` exports each file under `src/`, but fallow matched the target only against files on disk. Thus the public subpath files were unused files, and their exports were unused exports. A wildcard target now follows the rule of a single package entry: the last `dist`, `build`, `out`, `esm` or `cjs` directory becomes `src`, and a JavaScript output extension becomes each source extension. A `lib` target maps into `src` only when it matches no file. A target at the package root such as `./*.js` maps into `src`. When `src` has a match, the target still matches the files directly in the package root, but not the files in other directories such as `scripts/`. The root package of a project now also expands its wildcard `exports` targets, and a match skips the files of nested packages that have a `name`.

- **Workspace entry point paths no longer keep a `./` segment.** `fallow list --entry-points` showed `packages/a/./index.js` for the entry `./index.js` of a workspace package. The path is now `packages/a/index.js`, the same as in the other reports.
