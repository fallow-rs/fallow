### Fixed

- **`command-injection` reports an untrusted argument of `spawn` and `execFile` with the shell option on.** With `shell: true` or a shell path, Node joins the command and the arguments into one shell command line, so the shell also parses each argument. A call of `spawn`, `spawnSync`, `execFile` or `execFileSync` from `node:child_process` is now a candidate when its options object literal turns the shell on and its argument array holds untrusted input, for example `spawn("git", [req.query.ref], { shell: true })`. An options variable or an options object with a spread does not prove the shell option, so these calls stay out. An options object in the argument position is not an argument array, and a `spawn` call with a non-literal command gives one candidate, not two. (Closes [#4550](https://github.com/fallow-rs/fallow/issues/4550), closes [#4549](https://github.com/fallow-rs/fallow/issues/4549))
