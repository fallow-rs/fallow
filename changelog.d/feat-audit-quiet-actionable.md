### Changed

- **`fallow audit --quiet` now prints only the actionable part of the human, compact and markdown reports.** This is a behavior change for existing `--quiet` users. Before, `--quiet` removed only the progress output. Now the report also drops unchanged inherited findings, aggregate metrics (vital signs, health score, hotspots and other ranked lists) and the `stale` and `active` records of `health.thresholdOverrides`. The report keeps introduced and worsened findings, diff-risk findings, configuration errors, analysis failures, warnings about incomplete analysis, and the `insufficient` and `no_match` override records. `FALLOW_QUIET=1`, or `--ci` with an explicit `--format human`, `--format compact` or `--format markdown`, also sets quiet and gets this view. `--ci` alone prints SARIF, which keeps the complete report. A script that sets `FALLOW_QUIET=1` and posts the output of `fallow audit --format markdown` no longer gets the inherited context. The verdict, the exit code and the JSON, SARIF, CodeClimate, review and GitHub formats do not change. Run without `--quiet`, or use `--format json`, for the complete report.
  (Closes [#4575](https://github.com/fallow-rs/fallow/issues/4575))
