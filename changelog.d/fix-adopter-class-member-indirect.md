### Fixed

- **`fallow dead-code` credits a class member that code reads through `Pick`, `Omit`, `Partial`, `Required`, `Readonly` or `NonNullable` of the class.** With `constructor(private readonly coord: Pick<Coordinator, 'requests'>)`, `this.coord.requests()` now credits `Coordinator.requests`. A class field, a constructor parameter, an interface field and a function parameter with such a type also give the credit. Before, only a `type` alias of `Pick` gave it.

- **`fallow dead-code` credits a Durable Object method that a Worker calls through an RPC stub.** With `env: Env` and `Env { QUOTA: DurableObjectNamespace<DailyQuota> }`, fallow now credits `DailyQuota.take` for `const stub = env.QUOTA.getByName(name); stub.take()`, for `const stub = env.QUOTA.get(env.QUOTA.idFromName(name)); stub.take()`, and for a value typed `DurableObjectStub<DailyQuota>`. A `get()` call gives a stub only when its id comes from the same namespace, so a `get()` on a `Map` or on a repository class gives no credit. A stub from the global `env` of `cloudflare:workers`, or from a helper function that returns the stub, gives no credit yet. The extraction cache version is 436.
