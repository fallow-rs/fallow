### Fixed

- **A health baseline no longer accepts a new long file in the slot of a fixed function.** A count-mode health baseline counted a file-length finding as complexity, so when a function finding that the baseline accepted was fixed, a file that crossed `health.maxFileLines` used its slot and `fallow health --baseline` and `fallow audit` with `audit.healthBaseline` did not report it. File-length findings now have their own baseline categories (`file_lines_moderate`, `file_lines_high`, `file_lines_critical`), and a save marks the file with `file_lines_categories: true`. A baseline saved before this release gives the same results as before, and gets the fix when it is saved again. On that save, the shrink-only baseline check reports the new `file_lines_*` counts in `finding_counts` as growth once.
