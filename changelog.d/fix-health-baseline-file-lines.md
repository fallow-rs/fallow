### Fixed

- **A health baseline no longer accepts a new long file in the slot of a fixed function.** A count-mode health baseline counted a file-length finding as complexity, so when a function finding that the baseline accepted was fixed, a file that crossed `health.maxFileLines` used its slot and `fallow health --baseline` and `fallow audit` with `audit.healthBaseline` did not report it. File-length findings now have their own baseline categories (`file_lines_moderate`, `file_lines_high`, `file_lines_critical`). A baseline saved with `maxFileLines` on before this release holds its long files as complexity counts: save it again, or the next run reports those long files as new.
