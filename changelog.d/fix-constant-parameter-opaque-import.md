### Changed

- **The opt-in `constant-parameter` rule now skips each exported function when a module has an `import()` or a `require` call with an unknown source.** A call such as `import(name)`, `` import(`${name}`) `` or `require(name)` can load any module and call its exports, so the rule does not see each caller. In type-aware mode, the rule also skips the methods of each exported class. A function that no export exposes stays a candidate. An import that resolves to a file, or a pattern with a relative prefix such as `` import(`./plugins/${name}.ts`) ``, still blocks only the files that it matches. Under `--production`, such a call in a test file does not count. The cache format changes, so the first run after the upgrade parses each file again.
  (Closes [#4556](https://github.com/fallow-rs/fallow/issues/4556))
