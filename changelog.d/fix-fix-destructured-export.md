### Fixed

- **`fallow fix` keeps the export of a name that is in use in a destructured declaration.** One `export` keyword exports every name of `export const { a, b } = x;`, `export const [a, b] = x;` and `export const a = 1, b = 2;`. `fix` removed that keyword when only one name was unused, so the imports of the other names failed the type check (TS2306 or TS2459). `fix` now removes the keyword only when every name of the declaration is unused, also when the pattern spans several lines. Otherwise each unused name is a `remove_export` entry with `skip_reason: "shared_declaration_in_use"`, counted by the new JSON counter `skipped_shared_declarations`. The human output and the CI step summary state these entries. `fix` does not split the declaration, because a split evaluates the initializer twice and changes the value of a rest element. The exit code does not change.
  (Closes [#4659](https://github.com/fallow-rs/fallow/issues/4659))
