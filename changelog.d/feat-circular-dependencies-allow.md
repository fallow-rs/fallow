### Added

- **`circularDependencies.allow` accepts exact cycles.** Each entry lists the files of one cycle in import order, relative to the project root, for example `[["src/a.ts", "src/b.ts"]]`. An entry accepts only the cycle with exactly these files, from any start file. A new cycle through the same imports stays reported, which an inline `fallow-ignore-next-line circular-dependency` marker does not give. Paths are case-sensitive. An entry needs at least 2 files and lists each file once. An accepted cycle does not count toward the limit of 20 listed cycles per group of files that import each other. An entry that matches no cycle gives a `circular-dependencies-allow-unmatched` diagnostic in JSON, SARIF, Markdown and the stderr note. An entry that the detector cannot check (more than 12 files, or all files in a group that reached the limit) gives no diagnostic. A `fallow-ignore-next-line circular-dependency` comment on an accepted cycle becomes a stale suppression, so remove it when you add the entry. `fallow migrate` now translates the `cycles.allow` list of a migrated config. (Closes [#4623](https://github.com/fallow-rs/fallow/issues/4623))
