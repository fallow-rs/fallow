### Fixed

- **`absent-component-props` accepts a method signature in a props type.** Before, a props type with a member such as `onClose(): void` made the component abstain, so a never-passed optional prop was not reported. Now a method signature counts as a prop, the same as `onClose: () => void`. An overloaded method is optional only when every overload is optional. Call, construct, index and accessor members still keep the contract open. (Closes [#4022](https://github.com/fallow-rs/fallow/issues/4022))
- **`absent-component-props` reports props when the calling module queries the DOM.** Before, a call such as `document.getElementById`, `querySelector` or `createElement` anywhere in a module made every component that the module imports abstain. A DOM query can set a property on a custom element, but it cannot supply props to a React, Vue or other imported component. Now a DOM query, `innerHTML` or an unsafe Lit directive makes only Lit elements and imported Svelte components abstain. A Svelte component can compile to a custom element, so it still abstains. (Closes [#4023](https://github.com/fallow-rs/fallow/issues/4023))
