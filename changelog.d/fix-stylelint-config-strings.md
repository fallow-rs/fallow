### Fixed

- **`fallow dead-code` credits the modules that a Stylelint config names in `extends`, `plugins` and `customSyntax`.** Stylelint loads each string entry of these keys, at the top level and in each `overrides` entry, by package name or by path. Fallow credited only the imports of `stylelint.config.*` and `.stylelintrc.{js,cjs}`. It read nothing from `.stylelintrc`, `.stylelintrc.{json,yaml,yml}` or the `stylelint` key of a `package.json`. A shared config such as `@acme/config-stylelint` or a syntax such as `postcss-html` was then reported as an unused dependency. A local plugin such as `./plugin.js` was reported as an unused file. Fallow now also reads a config that an `extends` entry names, as a local path or as a workspace package inside the project. `stylelint.config.ts` and `.stylelintrc.mjs` are config files too.
