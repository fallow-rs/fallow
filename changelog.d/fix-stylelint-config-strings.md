### Fixed

- **`fallow dead-code` credits the modules that a Stylelint config names in `extends`, `plugins` and `customSyntax`.** Stylelint loads each string entry of these keys, at the top level and in each `overrides` entry, by package name or by path. Fallow credited only imports in `stylelint.config.*` and `.stylelintrc.{js,cjs}`, and nothing in `.stylelintrc`, `.stylelintrc.{json,yaml,yml}` or the `stylelint` key of the root `package.json`. A package declared in `dependencies`, or with a name that does not start with `stylelint`, such as a shared config `@acme/config-stylelint` or a syntax `postcss-html`, was reported as an unused dependency, and a local plugin such as `./plugin.js` was reported as an unused file. A config that an `extends` entry names, as a local path or as a workspace package, is now read the same way, when it is inside the project. Fallow now also reads `stylelint.config.ts` and `.stylelintrc.mjs`.
