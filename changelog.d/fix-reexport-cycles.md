### Fixed

- **`fallow dead-code` no longer reports `export * as Ns from "./self"` as a re-export self-loop.** A namespace re-export adds one named export and forwards no names, so chain propagation cannot loop through it. Fallow now keeps these edges out of the re-export cycle check, also for loops between two or more files. The `Re-export self-loop detected` warning for this form is gone too. (Closes [#4722](https://github.com/fallow-rs/fallow/issues/4722))
- **A circular dependency edge through a re-export now points at the `export ... from` statement.** Before, the edge from the barrel had line 1 and column 0, so editors and SARIF showed the finding on the first line of the file. A `fallow-ignore-next-line circular-dependency` comment above the re-export now also hides the cycle. (Closes [#4737](https://github.com/fallow-rs/fallow/issues/4737))
- **`fallow dead-code` no longer reports a false import cycle inside the `tailwindcss` package.** Fallow adds a `tailwindcss` import to each stylesheet with `@apply` or `@tailwind`. Inside the package named `tailwindcss`, that import resolved to the entry stylesheet of the package, for example `index.css`, and closed a cycle with a stylesheet that `index.css` imports. Fallow now skips this import when it resolves into the package that contains the stylesheet. (Closes [#4740](https://github.com/fallow-rs/fallow/issues/4740))
