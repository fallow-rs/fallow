### Fixed

- **`fallow dead-code` credits a member on the result of an awaited async static factory.** With `static async create(): Promise<Service>` in another file, `const service = await Service.create(); service.getConflicts()` now credits `Service.getConflicts`, as `Service.build()` with `static build(): Service` already did. The factory can build the instance in a local before it returns it.
- **`fallow dead-code` credits a member on an element of a typed array field of a class in another file.** With `days: Day[]` on `Month`, fallow now credits `Day` members for `m.days[0].getFirst()`, `m.days.some((day) => day.flag)` and `for (const day of m.days)`, where `m` is a parameter typed `Month`. The same is true for `this.days[0]?.getFirst()` in `Month`, and for a getter or a method that returns an array (`get sorted(): Day[]`). The extraction cache version is 427.
- **`fallow dead-code` credits a member of a page object that a Playwright fixture reaches through a property.** With the fixture `app: AppPage` and `readonly details: DetailsPage` on `AppPage`, `app.details.getParameter()` in a test now credits `DetailsPage.getParameter`. A longer chain (`app.details.input.select()`) also gives the credit when each property has a declared type or a `new` initializer. The chain also credits each property that it reads: `details` on `AppPage` and `input` on `DetailsPage`.
- **`fallow dead-code` credits a member on an element of an array that a function in another file returns.** With `export const make = (): Sheet[] => ...`, fallow now credits `Sheet` members for `make().forEach((sheet) => sheet.member)`, `for (const sheet of make())` and `make()[0].member`, and for the same reads through a local `const sheets = make()`. A function that returns one instance gives no credit for a read on an element of its result.
