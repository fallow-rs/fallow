### Fixed

- **`fallow dead-code` credits a package or file that code loads through an inline `createRequire(import.meta.url)('pkg')` call.** Fallow identified a load by the callee name `require`, so it reported the package as an unused dependency and the file as an unused file. Fallow now reads a `require` function based on the file itself in each spelling: the inline load, `.resolve` on the call, a binding with any name (`const req = createRequire(import.meta.url)`), `mod.createRequire(...)`, and `import { createRequire as cr }`. The base is `import.meta.url`, `import.meta.filename`, `__filename` or `fileURLToPath(import.meta.url)`. These forms now give the same findings as the named `require` form, so an inline load can also report an unresolved import, an unlisted dependency, or an unused export of the loaded file. A call with another base, such as `createRequire(process.cwd())('pkg')`, credits nothing. The extraction cache version changes, because cached results hold more load calls. Thanks @Smrtnyk for the report.
  (Closes [#4062](https://github.com/fallow-rs/fallow/issues/4062))
