### Added

- **`fallow mutation --typecheck` now adds an equivalence hint to an optional-chaining survivor.** The mutants `a?.b` to `a.b`, `a?.()` to `a()` and `a?.[k]` to `a[k]` change nothing when `a` is never nullish at run time. When the declared type of `a` excludes `null` and `undefined`, the survivor gets `equivalence_hint: "type-non-nullish"`. The hint is advisory. The mutant stays `survived` and stays in the score. The human report and `fallow mutation tasks` show a one-line note, and a verdict file (`--verdicts`) records the mutant as equivalent after review. `typecheck.hinted` counts the hinted survivors. The hint needs `strictNullChecks` and `noUncheckedIndexedAccess`. It can be wrong, for example for an optional property under `exactOptionalPropertyTypes`.
