### Added

- **`fallow mutation --typecheck` now marks an optional-chaining mutant as `equivalent` when the types prove it.** The mutants `a?.b` to `a.b`, `a?.()` to `a()` and `a?.[k]` to `a[k]` change nothing when the type of `a` excludes `null` and `undefined`. The mutant gets the status `equivalent` and `equivalent_reason: "type-proven-never-nullish"`, and it leaves the score. The proof needs `strictNullChecks` and `noUncheckedIndexedAccess`. It reads the declared type, not the narrowed type. It does not hold for `any`, `unknown`, a type parameter, an assertion, a declaration that no code checks, or a binding that code assigns after its declaration. `typecheck.equivalent` counts the proven mutants.
