### Added

- **`fallow mutation --kill-matrix-for <target>` checks whether named tests are redundant without a full kill matrix.** A target is a test file or a test ID (`file::name`). Repeat the flag for each target. Only the mutants that a target test covers run. Each mutant runs its target tests with bail disabled, then its other covering tests with bail enabled, up to the first failure. The other mutants are `pruned` with `prune_reason: "no-target-coverage"`. For each target test, `kill_matrix.tests` reports `kills`, `unique_kills` (kills that no other test detects), and the new `target_only_kills` field (kills that only other targets share, each with those targets). The new `kill_matrix.targets` field lists each target with the test IDs that it selects. A target that selects no test of the dry run exits `2` with `FALLOW_MUTATION_TARGET_UNMATCHED`. The flag and `--kill-matrix` are exclusive. Thanks for the detailed proposal.
  (Closes [#4061](https://github.com/fallow-rs/fallow/issues/4061))
