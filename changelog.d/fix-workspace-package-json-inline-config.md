### Fixed

- **`fallow dead-code` reads the inline tool config of a workspace `package.json`.** A tool key in the `package.json` of a workspace package, such as `"prettier": "@acme/config-prettier"` or `"prettier": { "plugins": [...] }`, now credits the packages it names, as the same key in the root `package.json` already did. Before, fallow read these keys only from the root manifest, so the config package of a workspace was reported as an unused dependency. The credit counts for the workspace manifest and the root manifest, not for a sibling workspace that declares the same package. The other values of the key apply to the workspace too, so they can change which files are reported as unused: for example `jest.setupFiles` and `jest.testMatch`, the `tsup`, `tsdown` and `tsd` entries, and the `release-it` and `commit-and-tag-version` setup files. The workspace skips the key when it has a config file of the same tool, as the root does. (Closes [#4530](https://github.com/fallow-rs/fallow/issues/4530))
