### Fixed

- **`fallow dead-code` reads the inline tool config of a workspace `package.json`.** A tool key in a workspace `package.json`, such as `"prettier": "@acme/config-prettier"`, now credits the packages that it names. Before, fallow read these keys only from the root manifest, so the config package of a workspace was reported as an unused dependency. The credit counts for the workspace manifest and each manifest above it, not for a sibling workspace that declares the same package. The other values of the key, such as `jest.setupFiles` and the `tsup` entries, apply to the workspace too and can change which files are reported as unused. The workspace skips the key when it has a config file of the same tool, as the root does. (Closes [#4530](https://github.com/fallow-rs/fallow/issues/4530))
