### Fixed

- **Package scripts and CI steps that run a local shell helper now credit the commands of that helper.** For `bash scripts/build.sh` or `./scripts/release.sh`, Fallow reads the helper without running it. A binary that the helper runs makes its package used, and a file that the helper runs with `tsx` or `node` becomes an entry. The helper path resolves in the package directory or in the `working-directory` of the CI step, and it must stay inside the project. Fallow follows nested helpers and stops at a cycle. It follows a `cd` to a literal directory or to the helper directory (`cd "$(dirname "$0")/.."`). After another `cd`, the remaining commands of the helper credit packages but do not add entries. (Closes [#3886](https://github.com/fallow-rs/fallow/issues/3886))
