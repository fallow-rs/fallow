### Added

- **New rule `unused-protected-class-members` reports `protected` class members that no code reads.** The rule is `off` by default, so the default output does not change. A protected member is used when its class or a subclass reads it through `this` or `super`. A subclass override is used when the base class calls the member. Classes of the public API of a package are not checked, because a consumer can subclass them. Production mode ignores reads in test files, as for public members. Turn the rule on in `rules`, select it with `--unused-protected-class-members`, and suppress one finding with `// fallow-ignore-next-line unused-protected-class-member`. The findings go to the new `unused_protected_class_members` array in JSON and reach SARIF, CodeClimate, the human report, the LSP and `fallow explain`. `unused-class-members` still does not report protected members. The extraction cache version and the graph cache version change, so the first run after the upgrade parses every file again.
  (Closes [#4624](https://github.com/fallow-rs/fallow/issues/4624))
