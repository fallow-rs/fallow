### Added

- **A boundary zone can mark the public entry files of a module with `"publicApi": true`.** Since 3.31.0, the boundary check follows a named or default import through re-export chains and judges it by the file that declares the symbol. That made the one-public-entry-file pattern (for example `src/modules/billing/public.ts`) report every import through the entry file. The chain walk now stops at the first file of a `publicApi` zone and judges the import by that file and its zone. A direct import of an internal file is still a violation, and so is a chain through a barrel that is not in a `publicApi` zone. Put the `publicApi` zone before the zone of its module, because a file gets the first zone that matches it. Add a rule for the `publicApi` zone to limit what its files may re-export. A zone cannot set `publicApi` together with `autoDiscover`. `fallow list --boundaries --format json` shows `public_api: true` on such a zone. (Closes [#4760](https://github.com/fallow-rs/fallow/issues/4760))
