### Fixed

- **`fallow fix` checks each edit before it writes it.** `fix` now applies its planned source edits to the text and compares the result with the original. It drops an edit when the file no longer parses, when a kept class or enum member is lost, when a kept enum member gets another value, when a name that the code uses loses its declaration, when an import stays after its name left an export list, or when the edit removes an export that other code still uses. The human output prints one `Kept <path>:<line>` line for each dropped edit, and the JSON output lists no entry for it. The editor quick fix and the review comment `suggestion` blocks use the same check. One result: `fix` no longer removes an exported enum whose members are all unused while another file imports the enum. (#4963, #4833, #4659)
