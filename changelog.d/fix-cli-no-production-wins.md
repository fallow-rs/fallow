### Fixed

- **`--no-production` now turns off a config `production: true` on every command.** On `fallow list`, `workspaces`, `fix`, `watch`, `viz`, `flags` and `suppressions`, a config with `production: true` won over `--no-production` and over `FALLOW_PRODUCTION=false`. These commands now use the same order as `fallow dead-code`: the flag, then the environment variable, then the config. The MCP `list_boundaries` tool now also lets an off `FALLOW_PRODUCTION` value turn off production mode, and the MCP `fix_preview`, `fix_apply` and `suppressions` tools now apply `production: false`. `fallow viz` now finds duplicates in the files of the duplication production mode. `fallow watch` now keeps the type-aware flags when it reloads the config. The VS Code sidebar now passes the `allowRemoteExtends` setting to the CLI.
