### Added

- **The focus map of the review brief now ranks changed files also by churn, complexity growth, test reach and surviving mutants.** The `score` of each focus unit can carry four new components: `churn` (the recency-weighted commit count of a source file), `worsened` (the changed functions whose complexity grew against the base), `test_reach` (the changed exports that no test runs for real) and `mutation` (the surviving mutants on added lines). The new `fallow audit --mutation-report <file>` flag reads a saved `fallow mutation --format json` report for the `mutation` component. Each component is capped, adds to `total`, and is absent while it is zero. The new components can change `total`, the label and the rank order of a unit, and the `reason` text gains one clause for each present component. `triage.risk_class` does not change. A run without a git history has no diff, so without `--mutation-report` it gives the same JSON as before.
  (Closes [#4505](https://github.com/fallow-rs/fallow/issues/4505))
