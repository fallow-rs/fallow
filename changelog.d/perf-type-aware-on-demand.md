### Changed

- **`npm install fallow` no longer installs the type-aware companion and TypeScript 7.** This makes the install about 30 MB smaller on every platform. Default analysis does not use the companion. A project that uses `--type-aware` or `mutation --typecheck`, or that turns on `typeAware` in its config, must now add it at the same version as `fallow`: `npm install --save-dev fallow-type-aware@<fallow version>`. A global `fallow` needs `npm install --global fallow-type-aware@<fallow version>`. For npx, start both packages together: `npx -p fallow@<version> -p fallow-type-aware@<version> fallow`. The GitHub Action and the GitLab template install the companion themselves. The `fallow` launcher now also finds the companion from the project root, so pnpm projects work too. Without the companion, `--type-aware` keeps the syntactic findings, and its warning and `fallow type-aware status` name the install command for a project, a global install and npx.
