### Changed

- **`--unused-deps` now selects only unused dependencies.** It selects `unused-dependency`, `unused-dev-dependency` and `unused-optional-dependency`. The new `--misplaced-deps` flag selects `type-only-dependency`, `test-only-dependency` and `dev-dependency-in-production`. A run with `--unused-deps` can report fewer findings. With `--ci`, `--fail-on-issues` or a placement rule at `error`, such a run can now exit 0 where it exited 1. Fallow prints one stderr note in this case. To keep the old selection, run `fallow dead-code --unused-deps --misplaced-deps`. Use `misplaced-deps` in MCP `issue_types` and in the Action and GitLab issue types, and `misplacedDeps` in the Node API. If you saved a regression baseline with `--unused-deps`, save it again, because the count comparison uses totals. Thanks [@Smrtnyk](https://github.com/Smrtnyk) for the report. (Closes [#4064](https://github.com/fallow-rs/fallow/issues/4064))
