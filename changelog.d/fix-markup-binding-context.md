### Fixed

- **An expression in markup gives the same facts as the same expression in a script.** A `dispatch("save")` call in the markup of a Svelte component now counts for `unused-svelte-event`, and the finding points at the markup tag. A Vue template call of `emit` or `$emit` now marks the event as used through the template parse, so `bus.emit("close")` no longer marks a declared `close` event as used. A component whose `<template>` uses another language, such as `lang="pug"`, reports no `unused-component-emit` finding, because fallow reads only HTML templates. A dynamic import, a call or a security sink in a Vue or Svelte template expression, an Astro template region or an inline HTML script now goes to the graph and to `fallow security` like the same code in a script. The extraction cache version moves, so the first run after the upgrade parses every file again.
  (Closes [#4942](https://github.com/fallow-rs/fallow/issues/4942))
