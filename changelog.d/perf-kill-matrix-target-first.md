### Changed

- **`fallow mutation --kill-matrix-for` runs the target tests first and stops when no target kills the mutant.** Such a mutant now gets the new status `not_killed_by_target`. It runs no other covering test and gets no survivor retry, and it does not count in the score. After a target kill, the other covering tests run fastest first up to the first kill. Only a kill by exactly one target test and no other test gets a retry, so one flaky run cannot make a test look necessary. Each target keeps the same `kills`, `unique_kills` and `target_only_kills`, with far fewer test runs. `--kill-matrix-full` keeps the earlier behavior, in which each mutant gets a final status. `kill_matrix.target_mode` names the mode (`target-first` or `full`). (Closes [#4588](https://github.com/fallow-rs/fallow/issues/4588))
