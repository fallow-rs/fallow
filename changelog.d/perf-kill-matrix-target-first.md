### Changed

- **`fallow mutation --kill-matrix-for` runs the target tests first and stops when no target kills the mutant.** Such a mutant now gets the new status `not_killed_by_target`. It runs no other covering test and gets no survivor retry. After a target kill, the other covering tests run fastest first up to the first kill. Only a kill by exactly one target test and no other test gets a retry, so one flaky run cannot make a test look necessary. A retry that does not kill again with the same tests makes the mutant `flaky`. For deterministic tests, each target keeps the same `kills`, `unique_kills` and `target_only_kills`, with fewer test runs. This mode has no score: `summary.score` is `null`, and `--min-score` exits 2. `--kill-matrix-full` keeps the earlier behavior, in which each mutant gets a normal status and the run has a score. `kill_matrix.target_mode` names the mode (`target-first` or `full`). (Closes [#4588](https://github.com/fallow-rs/fallow/issues/4588))
