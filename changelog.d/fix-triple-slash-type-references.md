### Fixed

- **A `/// <reference types="pkg" />` directive now uses the package `pkg`.** Before this fix, fallow did not read the directive, so a package that a file loaded only for its type augmentations was reported as an unused dependency. Fallow now records the directive as a type-only import of the package. The rules for `import type` apply: in production mode, a package in `dependencies` that only such directives use is reported as a type-only dependency. TypeScript reads a triple-slash directive only before the first statement of a file, so fallow ignores a directive after code. A `types` value that starts with `.` or `/` names a file and is ignored. `types="node"` is also ignored, because fallow always credits `@types/node`. The extraction cache and the graph cache are invalidated, so the first run after the upgrade re-parses all files.
