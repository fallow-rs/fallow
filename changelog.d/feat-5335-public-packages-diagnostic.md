### Added

- **A workspace package that looks published gets a `publicPackages` hint.** A package looks published when its `package.json` is not `"private": true` and has an `exports`, `main` or `module` field. When `publicPackages` does not list such a package and its entry publishes exports or members with findings, `workspace_diagnostics[]` gets a `public-package-candidate` entry. The entry names the package and the number of these findings, and it says to add the package to `publicPackages` if the project publishes it. Human output prints one note, Markdown output has a section, and SARIF has a configuration notification. The entry changes no finding, no count and no gate. ([#5335](https://github.com/fallow-rs/fallow/issues/5335))
