### Fixed

- **`banned-call`, `banned-effect` and `boundaries.calls.forbidden` report each call site.** Before, these rules reported only the first call of a callee path in a file. One `fallow-ignore-next-line` comment above that call hid every later call of the same path, so a gate passed that must fail. Now each call or `new` site gets its own finding, and a suppression comment covers only the site on its next line. After the upgrade, a project with repeated calls of a banned callee can see more findings. A baseline that you saved before the upgrade covers only the first site of each path, so the other sites show as new findings. The extraction cache version changes, so the first run after the upgrade does a full parse. (Closes [#4210](https://github.com/fallow-rs/fallow/issues/4210))
