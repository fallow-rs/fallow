### Fixed

- **Four option texts no longer mislead.** The first sentence of the `--lean` help now names the commands that accept the flag: dead-code, health and the combined report. The help also says that other commands and other output formats exit with code 2. The `about` text of `fallow setup-hooks` now starts with "Deprecated", so `fallow schema --cli-reference` and short command lists show the deprecation. The `duplicates.ignoreDefaults` config text now lists every built-in pattern, including the test and mock files (`**/*.test.*`, `**/*.spec.*`, `**/__tests__/**`, `**/__mocks__/**`). The GitHub Action inputs `production`, `skip-local`, `cross-language` and `ignore-imports` now say that `true` passes the flag and that `false` keeps the config value. For `ignore-imports`, the config value excludes imports by default.
  (Refs [#4856](https://github.com/fallow-rs/fallow/issues/4856))
