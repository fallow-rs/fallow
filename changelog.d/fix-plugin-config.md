### Fixed

- **A Jest `moduleNameMapper` target that names a package now credits that package.** A mapping such as `'\\.(css|less)$': 'identity-obj-proxy'` no longer gives an unused dev dependency for `identity-obj-proxy`. A target with a capture group after the package name, such as `lodash-es/$1`, credits `lodash-es`. (Closes [#4712](https://github.com/fallow-rs/fallow/issues/4712))
- **A Vite or Vitest alias with a regular expression `find` now credits a package replacement.** An entry such as `{ find: /\.(css|less)$/, replacement: 'identity-obj-proxy' }` in `resolve.alias` or `test.alias` no longer gives an unused dev dependency for `identity-obj-proxy`. (Closes [#4713](https://github.com/fallow-rs/fallow/issues/4713))
- **The Vite plugin reads the `build.rollupOptions.input` of each environment, and reads each input relative to its config file.** Vite 6 and later accept build options under `environments.<name>.build`. Fallow now makes the files that these inputs name into entry points. A Vite config in a workspace package, with `vite` only in the root manifest, also gives its `rollupOptions.input` and `lib.entry` files below that package. Before, Fallow read these values from the project root. The files and their imports are no longer reported as unused. A class in these files that implements an interface through a Vite `resolve.alias` import gets the credit of the interface members, so its implementing members are not reported either. (Closes [#4716](https://github.com/fallow-rs/fallow/issues/4716), [#4771](https://github.com/fallow-rs/fallow/issues/4771))
- **A root-relative import in an MDX file now resolves.** Docusaurus resolves an import such as `import Note from '/docs/partials/_note.md'` from the site directory. Fallow now resolves a root-relative MDX import from the directory of the file, the nearest package, or the project root, as it does for JavaScript and TypeScript. A target that Fallow does not analyze, such as a `.md` partial, counts as an external file. The import is no longer in `unresolved_imports`. (Closes [#4733](https://github.com/fallow-rs/fallow/issues/4733))

### Changed

- **The maintainer plugin reference lists the Playwright config parsing and the correct plugin count.** (Closes [#4710](https://github.com/fallow-rs/fallow/issues/4710))
