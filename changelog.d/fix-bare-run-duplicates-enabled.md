### Fixed

- **The bare `fallow` command no longer runs the duplication analysis when the config has `duplicates.enabled: false`.** The bare run read only `--only` and `--skip`, so a project that turned duplication detection off still got a `dupes` section and clone groups. `duplicates.enabled: false` now turns the analysis off in the bare run, as it does in `fallow audit`. `--only dupes` and the `fallow dupes` command name the analysis, so they still run it. When `--skip` then leaves no analysis, the error names the config key.
- **A `--dupes-baseline` flag that has no effect because of `duplicates.enabled: false` now gives a note on stderr.** The bare `fallow` command and `fallow audit` ignored the flag with no message. The exit code does not change, so a CI script that passes the flag keeps its result.
