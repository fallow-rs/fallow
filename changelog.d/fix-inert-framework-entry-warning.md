### Fixed

- **Config load now warns about a plugin that can never activate.** A `framework[]` entry or a plugin file with neither `detection` nor `enablers` did nothing and gave no message, so its files could appear as unused. An empty `enablers` list counts as no `enablers`. Fallow now prints `plugin '<name>': no detection or enablers declared, so the plugin can never activate. Add one of them, then run `fallow plugin-check`.` on stderr, one time for each plugin name. `--quiet`, `--ci` and `FALLOW_QUIET` keep the line. Findings, stdout and exit codes do not change, and the plugin stays inactive. The `entry` and `framework` schema descriptions now name the `support` role for a script that does not run in production, and the human `Dev dependencies used in production` section now links to the docs. Thanks @Smrtnyk for the report. (Refs [#4068](https://github.com/fallow-rs/fallow/issues/4068))
