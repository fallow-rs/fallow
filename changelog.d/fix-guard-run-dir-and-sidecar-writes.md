### Fixed

- **The `pr-comment-*` sidecar files use the same path check as `--output-file`.** The files in `FALLOW_PR_COMMENT_ENVELOPE_FILE`, `FALLOW_PR_DECISION_FILE` and `FALLOW_PR_DETAILS_FILE` are no longer written through a symlink that resolves outside the project root, the Git work tree, the CI workspace or the temp directory. Fallow prints a warning for each refused file and still renders the comment.
- **`fallow mutation` does not write or remove run directories through a symlink.** A symlink on the way to `<cache>/mutation/runs` or `<cache>/mutation/companion` that resolves outside the project, or into Git metadata or `node_modules`, now stops the run with `FALLOW_MUTATION_UNSAFE_CACHE_DIR`. This is the check that the analysis caches use. A symlink at `<cache>/mutation` or `<cache>/mutation/runs` stops the run with `FALLOW_MUTATION_CACHE_WRITE_FAILED`. Before, the removal of old run directories followed the link and removed directories in its target. The `.last-used` marker of a run directory and the `<cache>/.gitignore` file are no longer written through a symlink either.
