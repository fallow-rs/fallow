### Added

- **The MCP tool `inspect_target` returns the `cloud` section and the compact text.** Set `cloud: true` on a file target to run the same path as `fallow inspect --file <path> --cloud`. The CLI reads the key in the same order as the other cloud tools: `FALLOW_API_KEY` in the server environment, the keychain, then the credentials file. The key is never a tool parameter. `repo` selects the repository and needs `cloud: true`. The section has the CLI statuses `ok`, `no_key`, `plan_required`, `unavailable` and `untracked`. A status other than `ok` does not fail the call. The tool refuses `cloud: true` with a symbol target, as the CLI does. Set `format: "compact"` to get the plain text of `fallow inspect --format compact` (about 1 KB) instead of the JSON bundle. When the run requires complete type-aware evidence and does not get it, a compact call fails with the typed `FALLOW_TYPE_AWARE_INCOMPLETE` body, as a JSON call does.
  (Closes [#4001](https://github.com/fallow-rs/fallow/issues/4001))
