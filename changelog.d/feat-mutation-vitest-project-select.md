### Added

- **`fallow mutation` can select Vitest projects with `--runner-project`.** A root Vitest config can hold projects from separate config files, such as browser or server projects. The mutation companion cannot instrument those projects, so the run failed at setup even when the tests of interest were in an inline project. Now `--runner-project <name>`, which you can repeat, or the `mutation.runnerProjects` config key selects projects as the Vitest `--project` flag does, wildcards included. Each project that is not selected stays out of the run. A selected project from a separate config file still fails at setup, and a name that matches no project fails with the Vitest message. With a runner other than Vitest, a selection exits with code 2. (Closes [#4785](https://github.com/fallow-rs/fallow/issues/4785))
