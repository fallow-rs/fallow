### Fixed

- **`--type-aware-require complete` no longer fails on a member with two or more exact uses.** Before, a `symbol-use` result kept one evidence item and reported the other references as an `evidence-limit` gap. A `confirmed-used` result was then `partial`, and the strict gate failed the run. Now a `symbol-use` result keeps one evidence item for each file that references the symbol, up to 40 items, and a `confirmed-used` result with truncated evidence is `complete`. Thus a read in a reachable file still credits the use when an unreachable file references the member first. `total_evidence_count` and `truncated` still report the number of references. Other gaps, for example `dynamic-member-access`, still make the result `partial`. A negative assertion, for example `confirmed-no-static-references`, still needs complete evidence. When the 40 returned items give no reachable read and the limit dropped references, the candidate now shows the `evidence-limit` reason. (Closes [#4229](https://github.com/fallow-rs/fallow/issues/4229))
