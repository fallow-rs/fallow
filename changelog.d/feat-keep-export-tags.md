### Added

- **`keepExportTags` selects the JSDoc tags that keep an export alive** ([#5081](https://github.com/fallow-rs/fallow/issues/5081)). An export with an `@internal`, `@alpha` or `@beta` tag never got an `unused-export` finding, and no option turned this off. A common use of the tag is `/** @internal Exported for tests. */`: when the last test that used the export went away, the gate stayed silent. The new key lists the tags that keep an export. The default is all four tags (`public`, `internal`, `alpha`, `beta`), so the behavior does not change. Set `"keepExportTags": ["public"]` to check `@internal`, `@alpha` and `@beta` exports like untagged exports. A tag that is not in the list also gives no credit to the source of a tagged re-export. `fallow dead-code --trace <file>:<export>` now names the tag when a tag keeps an export with no consumer, and the JSON trace has the new field `kept_by_tag`.
