### Changed

- **The `@fallow-cli` platform packages no longer contain the similar-code companion.** Each platform package is 9 to 12.5 MB smaller. Only `fallow similar-code` and the MCP `find_similar_code` tool use the companion. A project that uses them installs it at the same version as `fallow`: `npm install --save-dev fallow-similar-code@<fallow version>`. The `fallow` launcher finds the package, verifies it, and passes its binary to Fallow, which verifies the Ed25519 signature again before it runs it. The release archives on GitHub keep the companion next to the CLI binaries. Without the companion, `fallow similar-code status` names the install command.
