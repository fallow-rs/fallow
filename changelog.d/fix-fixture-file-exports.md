### Changed

- **Fallow reports an unused export of a fixture file that a test imports by name.** The Vitest, Jest and Playwright plugins make each file below `fixtures/` or `__fixtures__/` an entry point, so fallow never checked its exports. Now, when a module outside the fixture directories imports a name from such a file, fallow checks its exports like those of any other module, and also checks each fixture file that it imports by name. The file stays an entry point, so it is never an unused file, and its default export stays used. A fixture file that no module imports by name, that a dynamic import, an import pattern or `require()` loads, that only a side-effect import loads, whose fixture has its own `package.json`, or that another entry rule also matches keeps the old behavior. A project can get new `unused-export` and `unused-type` findings. (Closes [#5082](https://github.com/fallow-rs/fallow/issues/5082))
