### Added

- **`fallow-ignore-start` and `fallow-ignore-end` suppress one clone.** Put `// fallow-ignore-start code-duplication -- <reason>` above a block and `// fallow-ignore-end code-duplication` below it. A clone inside the range is not reported. A clone that reaches into the range is cut at the range border, and a cut part below `minTokens` or `minLines` is not reported. The `/* */`, JSDoc and `<!-- -->` forms work too, each on its own line. A marker in a string or template literal does not count. Ranges support only `code-duplication`. `fallow dupes` and `fallow audit` report a range marker with a problem (an end with no start, a nested start, a start with no end, no kind, or another kind) in the new `range_marker_problems` array, and such a marker has no effect. `fallow suppressions` lists ranges with `level: "range"` and `end_line`. Clone groups get a `suppress-range` action next to `suppress-line`. A missing reason on a range start shows `is_range: true` in its suppression origin. A range cuts its neighbor clones, so a baseline gate can show a cut clone as new, and its `ignoredClones` key changes: save the baseline again after you add a range. The duplication token cache and the extraction cache are rebuilt once after the upgrade.
  (Closes [#4706](https://github.com/fallow-rs/fallow/issues/4706))
