### Fixed

- **`fallow dead-code` credits a package that a stylesheet `url()` names.** A `url("@acme/font-sans/files/sans-latin.woff2")` in the `src` of an `@font-face`, or any other `url()` that names a file of a package, now counts as a use of that package. This applies to `.css`, `.scss`, `.sass` and `.less` files and to the plain CSS, SCSS and Sass `<style>` blocks of Vue and Svelte files. Before, fallow read only `@import`, `@use`, `@forward` and `@plugin`, so a font package that a stylesheet loads only through `url()` was reported as an unused dependency. Vite and webpack `css-loader` try a value such as `url(font-serif/files/a.woff2)` relative to the stylesheet first and then as a package path, so the value credits `font-serif`, and `url(~name/file)` credits `name`. A `?query` or `#fragment` at the end, as in `url("pkg/font.eot?#iefix")`, does not change the credit. Only a declared dependency gets the credit, so a value that names a local folder or a bundler alias, such as `url(@images/icons/arrow.svg)`, reports nothing. Relative, absolute, `data:`, remote and `#` values, the `@/` alias and SCSS or Less interpolation and variables name no package. The extraction cache version and the graph cache version change, so a warm cache does not give the old result.
