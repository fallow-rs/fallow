### Fixed

- **`fallow dead-code` credits a package that a stylesheet `url()` names.** A `url("@acme/font-sans/files/sans-latin.woff2")` in the `src` of an `@font-face` now counts as a use of that package. Before, a font package that a stylesheet loads only through `url()` was reported as an unused dependency. The credit applies to `.css`, `.scss`, `.sass` and `.less` files and to the CSS, SCSS and Sass `<style>` blocks of Vue and Svelte files. Unscoped (`url(name/file)`) and `~name/file` values credit `name` too, and a `?query` or `#fragment` suffix does not change the credit. Only a declared dependency gets the credit, so a local folder or a bundler alias such as `url(@images/icons/arrow.svg)` reports nothing. The extraction cache version and the graph cache version change.
