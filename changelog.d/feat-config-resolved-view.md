### Added

- **`fallow config --resolved` shows the settings of a run and where each one comes from.** For each analysis it shows whether it runs and its production mode, with the cause: a flag, an environment variable, a config key with its file, or a default. It also shows the thread count, the cache directory and the other run settings. Use `--for audit`, `--for dead-code`, `--for dupes` or `--for health` to see the rules of another command, and `--only`, `--skip` and `--production-dead-code`, `--production-health`, `--production-dupes` to see the effect of those flags. Environment variables show by name only. The JSON goes to stdout for each output format; a config that does not resolve exits 2 with a structured error. `fallow config` without `--resolved` does not change.
