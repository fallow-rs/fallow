# Governance

Fallow is an open-source project under the MIT license.

## Roles

| Role | Who | Responsibilities |
| --- | --- | --- |
| Maintainer | [@BartWaardenburg](https://github.com/BartWaardenburg) | Owns the roadmap, reviews and merges pull requests, publishes releases, holds the release and signing credentials, and handles security reports. |
| Contributor | Anyone | Opens issues, discussions and pull requests under [CONTRIBUTING.md](CONTRIBUTING.md). |

The project has one maintainer today.
The maintainer holds all access to the repository, the npm packages and the release signing key.

## Decisions

- The maintainer makes the final decision on scope, design and releases.
- Contributors can propose a change in an issue or a discussion before they write code.
- Each change to `main` goes through a pull request and the required status checks.
- Breaking changes follow [docs/backwards-compatibility.md](docs/backwards-compatibility.md).

## Security

Report vulnerabilities as described in [SECURITY.md](SECURITY.md).
The maintainer answers within 48 hours.

## Adding maintainers

The maintainer can invite a contributor who has a record of sound reviews and merged work.
The new maintainer gets repository access first.
Access to release credentials follows after the maintainer rotates them as described in [SECURITY.md](SECURITY.md).
This file lists every maintainer.

## Conduct

All participants follow the [Code of Conduct](CODE_OF_CONDUCT.md).
